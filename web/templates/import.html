Thêm dữ liệu Lazada và Shopee

Lazada và Shopee chặn chương trình tự động, nên EcomCheck không tự gọi hai sàn này. Bạn tìm kiếm như bình thường trên trình duyệt của mình, lưu lại nhật ký mạng (file HAR), rồi tải file lên đây. Kết quả được gộp vào lần tìm kiếm “{{ run.keyword }}” để so sánh với Tiki.

Lazada

40 sản phẩm mỗi trang

  1. Mở Chrome hoặc Edge, nhấn F12, chọn tab Network và bật Preserve log.
  2. Vào lazada.vn, tìm “{{ run.keyword }}”.
  3. Chuyển qua trang 2, 3, 4… như khi xem bình thường.
  4. Bấm nút tải xuống trong tab Network (Export HAR), chọn bản sanitized và lưu file .har.

Shopee

60 sản phẩm mỗi trang

  1. Đăng nhập shopee.vn như bình thường.
  2. Nhấn F12, chọn tab Network và bật Preserve log.
  3. Tìm “{{ run.keyword }}” rồi chuyển qua vài trang kết quả.
  4. Bấm Export HAR, chọn bản sanitized và lưu file .har.

Tải file lên

Nhận file .har (có thể chọn nhiều file cùng lúc), hoặc một phản hồi tìm kiếm đã lưu dạng .json, hoặc trang Lazada đã lưu dạng .html. Ứng dụng chỉ đọc phần kết quả tìm kiếm trong file và không lưu file lại. Bản sanitized không chứa cookie; dù vậy đừng đưa file .har lên GitHub.

Hai sàn này không gửi tên danh mục, nên danh mục được dự đoán từ tên sản phẩm bằng một mô hình học từ các sản phẩm Tiki của chính lần tìm kiếm này. Sản phẩm mô hình không chắc chắn sẽ để “Chưa phân loại”.
